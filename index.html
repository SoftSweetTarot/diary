🧰 상단 버튼 설명
🎨 스티커 : 이모지 스티커 목록을 엽니다. 카테고리 탭에서 고른 뒤 이모지를 누르면 페이지에 붙습니다.
✏️ 글쓰기 : 페이지에 글상자를 추가합니다. 상자 안을 눌러 내용을 입력하세요. 글상자를 선택하면 글상자 바로 옆에 글꼴 / 색상 / 크기 옵션창이 붙어서 나타납니다. (아래 '글상자 꾸미기' 참고)
🖼️ 이미지 : 내 PC·스마트폰 어느 폴더에 있는 이미지든 골라서 페이지에 넣을 수 있습니다. 이미지는 일기와 함께 저장되므로 원본 파일을 옮기거나 지워도 깨지지 않아요. (JPG·PNG·WEBP·움직이는 GIF 등)
📚 라이브러리 : 📚 라이브러리를 누르면 이미지들이 바둑판으로 나타나고, 원하는 이미지를 누르면 페이지에 들어갑니다. 위쪽 ◀ 이전 / 다음 ▶ 버튼(스마트폰은 옆으로 밀기)으로 페이지를 넘기고, 가운데 3 / 20 표시로 지금 몇 번째 페이지인지 볼 수 있어요. ⚙ 배치에서 한 줄에 몇 개(옆으로)·몇 줄(아래로)·이미지 크기를 바꿀 수 있습니다. (기본: 한 줄에 5개씩 3줄 = 한 페이지 15개, 기기마다 따로 기억)
⬆️ 앞으로 : 선택한 요소를 다른 요소들보다 맨 앞으로 가져옵니다.
⬇️ 뒤로 : 선택한 요소를 맨 뒤로 보냅니다.
🗑️ 삭제 : 선택한 요소(스티커·글상자·이미지)를 지웁니다.
💾 저장 : 누르면 저장 방법을 고르는 창이 떠요.
· ☁ 웹에 저장 (구글 드라이브) : 현재 날짜 페이지를 구글 드라이브의 '말랑달콤 / 다이어리 / 년도 / 월 / 일.json' 파일에 저장합니다. 폴더와 파일이 없으면 새로 만들고, 같은 날짜는 하루 1개 파일에 계속 덮어씁니다. 변경 후 몇 초 뒤와 설정한 주기마다 자동으로도 저장되며, 스마트폰·아이패드 화면이 꺼지거나 앱을 벗어나는 순간에도 자동 저장됩니다.
· 🖼 내 기기에 사진(PNG)으로 저장 : 지금 페이지를 그림 파일로 내려받아요.
※ 화면 왼쪽 아래 ☁ 표시로 웹 저장 상태를 확인할 수 있어요. 📂 백업은 내 PC에 파일로 따로 보관합니다.
🖼 사진(PNG)으로 저장 : 💾 저장을 누르고 🖼 내 기기에 사진(PNG)으로 저장을 고르세요. 지금 페이지가 2배 해상도 .png 그림 파일로 컴퓨터·폰에 내려받아져요.
👧 인형 (🎠 놀이터 → 👧 인형방) : 내가 만든 인형들을 보고, 📔 붙이기로 지금 페이지에 붙여요. 붙인 인형은 스티커처럼 옮기고 돌리고 크기를 바꿀 수 있고, 두 번 누르면 표정·좌우 반전을 바로 바꿀 수 있어요. ✏️ 새 인형 만들기를 누르면 인형방이 열려요.
👧 인형방 (🎠 놀이터 → 👧 인형방 → ✏️ 새 인형 만들기) : 마네킹에서 시작해 ① 체형 → ② 피부 → ③ 눈·코·입 → ④ 헤어 → ⑤ 화장 → ⑥ 옷 → ⑦ 소품 → ⑧ 완성 순서로 인형을 만들어요. ③~⑦은 😊 쉬움(고르기)과 🔥 어려움(직접 그리기) 중에 고를 수 있어요.
· 어려움 펜 : 점을 찍으면 선이 따라오고, 다음 점을 찍어 이어 가다가 첫 점을 누르면 닫히면서 색이 채워져요. 누른 채 끌면 곡선, 두 번 누르면 열린 선으로 끝나요. 붓으로 칠하고, 고르기로 조각을 옮기거나 점을 끌어 고칠 수 있어요. ↔ 좌우 대칭, 되돌리기, 확대도 있어요.
· 만든 시간·조각 수·점 수가 제작 기록으로 남아요. ⑧ 완성에서 📷 사진으로 저장(카페 자랑용 카드), 💾 인형 파일로 저장, ▶ 만드는 과정 다시보기, 📔 일기에 붙이기를 할 수 있어요.
· 인형은 내 구글 드라이브 / 말랑달콤 / 인형 폴더에 인형마다 파일 하나로, 인형 이름으로 저장돼요. (예: 로라.json · 최대 50개) 같은 이름이 있으면 바꿀지 물어봐요.
· 만들다 닫아도 이 기기에 임시 저장돼서 이어서 만들 수 있어요.
👗 스킨 : 세 가지 메뉴가 있어요.
· 🎨 기본스킨 : 기본 스킨 4종, 🌟 모두의 스킨(카페에서 받아 등록된 스킨), 🎨 내 스킨 중에서 고르거나, 색상을 직접 골라 나만의 스킨을 만들어 등록/삭제할 수 있어요. 고른 스킨은 구글 드라이브 설정에 저장되어 다음에 열어도 그대로예요. 창 제목을 끌면 창을 옮길 수 있고, 👀 꾹 눌러 보기를 누르고 있으면 창이 투명해져서 다이어리 색을 확인할 수 있어요. 📤 카페에 스킨 공유에서 내 스킨을 💾 파일로 저장해 카페에 올리면 모든 사용자의 목록에 등록될 수 있고, 카페에서 받은 스킨 파일은 📥 스킨 파일 넣기로 바로 내 스킨에 넣을 수 있어요.
· 🆓 무료패턴 / 💎 유료패턴 : 다이어리 뒤 전체 배경에 패턴을 깔아요. 목록에서 누르면 바로 적용되고, 패턴 크기 조절과 패턴 해제도 할 수 있어요. 고른 패턴은 구글 드라이브 설정에 저장되어 다른 기기에서도 똑같이 보여요. 목록은 라이브러리처럼 ◀ 이전 / 다음 ▶ 으로 넘기고, ⚙ 배치에서 한 줄에 몇 개·몇 줄·크기를 바꿀 수 있어요.
· 📂 내 패턴 : 내가 만든 패턴 모음이에요. 누르면 배경에 적용되고, 💾 로 카페에 올릴 파일을 저장하거나 🗑 로 지울 수 있어요.
· ✏️ 패턴 직접 만들기 : 🧵 무늬 메이커(줄무늬·도트·깅엄 체크·격자·물결), 🖼️ 이미지 패턴(내 이미지를 바둑판·엇갈림으로 반복), 🖌️ 그려서 만들기(한 칸을 그리면 이어 붙인 모습이 바로 보여요. 이어그리기를 켜면 경계가 자연스럽게 이어져요)로 나만의 패턴을 만들 수 있어요. 만든 패턴을 💾 파일로 저장해서 말랑달콤 카페에 첨부해 올리면, 확인 후 모든 사용자의 패턴 목록에 닉네임과 함께 등록될 수 있어요.
🎠 놀이터 : 👧 인형방, 🎭 인형극, 🎬 달콤영상, 🔮 포춘카드, 🌙 꿈해몽, 🕹️ 오락실, 📚 만화방, 🎵 음악듣기, 🎁 랜덤박스, 🛍️ 말랑상점, ☕ 카페 이동, ❓ 도움말 등 여러 가지 기능을 모아 둔 창을 엽니다.
⚙ 설정 : 네 가지 메뉴가 있어요.
· 📐 페이지 크기 : 다이어리 가로·세로 크기를 바꿔요. 작은 창이라 바뀐 크기를 보면서 조절할 수 있고, 제목을 끌면 창이 옮겨지고 👀 꾹 눌러 보기로 창을 잠깐 투명하게 할 수 있어요.
· ⚙️ 설정 : 전체 UI 폰트, 자동 저장 주기(1~60분), 💾 데이터 관리(백업·불러오기·로그아웃), 저장 용량 확인
· 💌 건의함 · 💝 후원
🖐️ 요소 다루기 (스티커·글·이미지)
선택 : 요소를 누르면 점선 테두리와 조절 핸들이 나타납니다. 빈 곳을 누르면 선택이 풀립니다.
이동 : 요소를 끌어서 원하는 위치로 옮깁니다.
🔄 회전 : 위쪽의 빨간 핸들을 끌어 회전합니다.
↘ 크기 조절 : 오른쪽 아래의 초록 핸들을 끌어 크기를 바꿉니다. PC에서는 요소 위에서 마우스 휠로도 조절됩니다.
💾 백업 · 불러오기 · 용량 확인
위치 : ⚙️ 설정 → 💾 데이터 관리
