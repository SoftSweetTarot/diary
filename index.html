🧰 상단 버튼 설명
🎨 스티커 : 이모지 스티커 목록을 엽니다. 카테고리 탭에서 고른 뒤 이모지를 누르면 페이지에 붙습니다.
✏️ 글쓰기 : 페이지에 글상자를 추가합니다. 상자 안을 눌러 내용을 입력하세요. 글상자를 선택하면 글상자 바로 옆에 글꼴 / 색상 / 크기 옵션창이 붙어서 나타납니다. (아래 '글상자 꾸미기' 참고)
🖼️ 이미지 : 내 PC·스마트폰 어느 폴더에 있는 이미지든 골라서 페이지에 넣을 수 있습니다. 이미지는 일기와 함께 저장되므로 원본 파일을 옮기거나 지워도 깨지지 않아요. (JPG·PNG·WEBP·움직이는 GIF 등)
📚 라이브러리 : 📚 라이브러리를 누르면 이미지들이 바둑판으로 나타나고, 원하는 이미지를 누르면 페이지에 들어갑니다. 위쪽 ◀ 이전 / 다음 ▶ 버튼(스마트폰은 옆으로 밀기)으로 페이지를 넘기고, 가운데 3 / 20 표시로 지금 몇 번째 페이지인지 볼 수 있어요. ⚙ 배치에서 한 페이지의 행·열 개수와 이미지 크기를 바꿀 수 있습니다. (기본 3행 5열, 기기마다 따로 기억)
⬆️ 앞으로 : 선택한 요소를 다른 요소들보다 맨 앞으로 가져옵니다.
⬇️ 뒤로 : 선택한 요소를 맨 뒤로 보냅니다.
🗑️ 삭제 : 선택한 요소(스티커·글상자·이미지)를 지웁니다.
💾 저장 : 현재 날짜 페이지를 구글 드라이브의 '말랑달콤 / 다이어리 / 년도 / 월 / 일.json' 파일에 저장합니다. 폴더와 파일이 없으면 새로 만들고, 같은 날짜는 하루 1개 파일에 계속 덮어씁니다. 변경 후 몇 초 뒤와 설정한 주기마다 자동으로도 저장되며, 스마트폰·아이패드 화면이 꺼지거나 앱을 벗어나는 순간에도 자동 저장됩니다.
※ 화면 왼쪽 아래 ☁ 표시로 저장 상태를 확인할 수 있어요. 📂 백업은 내 PC에 파일로 따로 보관합니다.
📷 PNG 저장 : 현재 보고 있는 페이지를 .png 이미지로 저장합니다. 현재 페이지 크기의 2배 해상도로 저장됩니다.
👗 스킨 : 세 가지 메뉴가 있어요.
· 🎨 기본스킨 : 기본 스킨 4종을 고르거나, 색상을 직접 골라 나만의 스킨을 만들어 등록/삭제할 수 있습니다.
· 🆓 무료패턴 / 💎 유료패턴 : 다이어리 뒤 전체 배경에 패턴을 깔아요. 목록에서 누르면 바로 적용되고, 패턴 크기 조절과 패턴 해제도 할 수 있어요. 고른 패턴은 구글 드라이브 설정에 저장되어 다른 기기에서도 똑같이 보여요. 목록은 라이브러리처럼 ◀ 이전 / 다음 ▶ 으로 넘기고, ⚙ 배치에서 행·열·크기를 바꿀 수 있어요.
🛎️ 서비스 : 도움말, 카페 이동, 타로점, 음악 듣기, 랜덤박스 등 부가 서비스를 모아 둔 창을 엽니다.
⚙️ 설정 : 전체 UI 폰트, 페이지 크기, 자동 저장 주기(1~60분), 💾 데이터 관리(백업·불러오기·용량 확인), 💌 건의함, 💝 후원하기가 있습니다.
🖐️ 요소 다루기 (스티커·글·이미지)
선택 : 요소를 누르면 점선 테두리와 조절 핸들이 나타납니다. 빈 곳을 누르면 선택이 풀립니다.
이동 : 요소를 끌어서 원하는 위치로 옮깁니다.
🔄 회전 : 위쪽의 빨간 핸들을 끌어 회전합니다.
↘ 크기 조절 : 오른쪽 아래의 초록 핸들을 끌어 크기를 바꿉니다. PC에서는 요소 위에서 마우스 휠로도 조절됩니다.
💾 백업 · 불러오기 · 용량 확인
위치 : ⚙️ 설정 → 💾 데이터 관리
📂 백업 : 모든 날짜의 일기를 하나의 .json 파일로 내려받습니다.
📥 불러오기 : 백업 .json을 선택해 복원합니다.
