❓ 도움말 : 지금 보고 있는 이 설명창을 엽니다.
🎨 스티커 : 이모지 스티커 목록을 엽니다. 카테고리 탭에서 고른 뒤 이모지를 누르면 페이지에 붙습니다.
✏️ 글쓰기 : 페이지에 글상자를 추가합니다. 상자 안을 눌러 내용을 입력하세요. 글상자를 선택하면 글상자 바로 옆에 글꼴 / 색상 / 크기 옵션창이 붙어서 나타납니다. (아래 '글상자 꾸미기' 참고)
🖼️ 이미지 : my_lovely_diary.html 파일이 있는 곳에 images 폴더를 만들고 이미지를 모두 넣고 이미지를 고르세요.
반드시 images 폴더 안에 파일을 넣고 이미지를 고르세요. 안그러면 저장이 안되어 이미지가 깨집니다.
📚 라이브러리 : 📚 라이브러리를 누르면 이미지들이 바둑판으로 나타나고, 원하는 이미지를 누르면 페이지에 들어갑니다.
⬆️ 앞으로 : 선택한 요소를 다른 요소들보다 맨 앞으로 가져옵니다.
⬇️ 뒤로 : 선택한 요소를 맨 뒤로 보냅니다.
🗑️ 삭제 : 선택한 요소(스티커·글상자·이미지)를 지웁니다.
💾 저장 : 현재 날짜 페이지를 구글 드라이브의 '다이어리 / 년도 / 월 / 일.json' 파일에 저장합니다. 폴더와 파일이 없으면 새로 만들고, 같은 날짜는 하루 1개 파일에 계속 덮어씁니다. 변경 후 몇 초 뒤와 설정한 주기마다 자동으로도 저장되며, 스마트폰·아이패드 화면이 꺼지거나 앱을 벗어나는 순간에도 자동 저장됩니다.
※ 화면 왼쪽 아래 ☁ 표시로 저장 상태를 확인할 수 있어요. 📂 백업은 내 PC에 파일로 따로 보관합니다.
📷 PNG 저장 : 현재 보고 있는 페이지를 .png 이미지로 저장합니다. 현재 페이지 크기의 2배 해상도로 저장됩니다.
👗 스킨 : 기본 스킨 4종을 고르거나, 색상을 직접 골라 나만의 스킨을 만들어 등록/삭제할 수 있습니다.
⚙️ 설정 : 전체 UI 폰트, 페이지 크기, 자동 저장 주기(1~60분), 💾 데이터 관리(백업·불러오기·용량 확인), 키보드 단축키를 바꿉니다.
🖐️ 요소 다루기 (스티커·글·이미지)
선택 : 요소를 누르면 점선 테두리와 조절 핸들이 나타납니다. 빈 곳을 누르면 선택이 풀립니다.
이동 : 요소를 끌어서 원하는 위치로 옮깁니다.
🔄 회전 : 위쪽의 빨간 핸들을 끌어 회전합니다.
↘ 크기 조절 : 오른쪽 아래의 초록 핸들을 끌어 크기를 바꿉니다. PC에서는 요소 위에서 마우스 휠로도 조절됩니다.
💾 백업 · 불러오기 · 용량 확인
위치 : ⚙️ 설정 → 💾 데이터 관리
📂 백업 : 모든 날짜의 일기를 하나의 .json 파일로 내려받습니다.
📥 불러오기 : 백업 .json을 선택해 복원합니다.
📊 용량 확인 : 다이어리 저장가능 용량을 확인 할 수 있습니다.
